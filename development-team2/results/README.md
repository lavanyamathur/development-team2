# Results

Organize results by genome, then variant:

```
results/
├── ecoli-dh5a/
│   ├── full/
│   │   ├── quast_report/
│   │   └── NOTES.md
│   ├── half/
│   └── quarter/
└── chr19-or-chr21/
    ├── full/
    ├── half/
    └── quarter/
```

Each `NOTES.md` should briefly note: what was run, the config used, any deviations, and a one-line takeaway. See `CONTRIBUTING.md` section 4 for details.
